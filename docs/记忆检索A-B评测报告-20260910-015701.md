## 六、差异归因

| 改动 | 作用层 | 影响的指标 |
|---|---|---|
| textSearch 至少命中半数 term（minHits）+ termHitCount 排序 | 召回 | 负样本误注入率、正样本 Hit@1 |
| 融合分下限 minScoreFloor=0.25 | 召回 | 负样本误注入率 |

| 移除 textMatched 兜底 0.35 | 打分 | 负样本误注入率 |
| 多 query 全局收敛（globalTopN=5） | Advisor | 多 query 注入条数与字符数 |
| 全局精排 + 相关性闸门（rerank 关闭时静默降级） | Advisor | 后续开启 rerank 后生效 |

## 八、结论与建议

1. **降噪收益确凿**：新版负样本误注入率 12.5% → 0.0%，正样本平均注入条数 2.00 → 1.44，多 query 注入条数 5.67 → 4.33（字符数 -20%）。
2. **记忆纯度提升**：旧版正样本 Top5 中混入了 `dialogueTip`、`povRule`、`chapterLen`、`oldInjury`、`sword` 等无关记忆（OR 单 term 命中 + 重要度加性偏置导致），新版 Top5 基本只剩目标记忆。
4. **建议**：把 `genwriter.long-term-memory.retrieval.similarity-threshold` 从 0.65 下调到 **0.55** 附近（阈值扫描中 [0.50, 0.55] 各档均达成「新版 Hit@5=100% 且误注入率 0%」），即可在召回不掉的前提下拿到全部降噪收益；若不便调阈值，则应放宽 `minHits`（当前为 ceil(term 数/2)）或为短 query 单独放开下限。
