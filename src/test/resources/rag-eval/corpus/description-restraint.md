# 描写的克制

## 形容词是负债

形容词越多，画面越模糊。写"一座阴森的老房子"不如写"门框上还挂着去年的封条，边角卷了起来"。前者替读者下了判断，后者让读者自己判断。凡是能被动作或细节替代的形容词，都应删掉。

形容词的问题在于它传播的是结论而不是证据。读者被迫接受一个已经加工好的印象，参与感被剥夺。而具体细节提供的是证据，读者据此自行得出结论，那个结论会因为属于他自己而停留得更久。这也是为什么优秀的描写段落里形容词密度通常很低。

## 读者的想象力更贵

留白不是信息缺失，而是把一部分画面交给读者完成。描写到七分，读者会自动补足剩下的三分，并且因为参与了创造而更有代入感。写满十分，读者只能被动接收。

留白的尺度需要把握。留白过多会让读者感到作者在敷衍，留白过少会让读者感到作者在唠叨。判断标准是：留下的空白是否有一个明确的边界。读者应该知道自己需要补的是什么，模糊一片的留白不是克制，而是失职。

## 副词与情绪标注

"他愤怒地说"是情绪标注。删掉副词，让台词本身的措辞体现愤怒，效果更好。同理，"非常""极其""相当"这类程度副词在绝大多数场合都是可以删掉的冗余。

更隐蔽的一类情绪标注是把情绪写成身体反应的同时加上解释，例如"他的手在抖，说明他很害怕"。前半个句子已经完成了全部工作，后半句把读者当成了需要提示的人。删除提示之后，读者反而会更仔细地读前半个句子。

## 克制的例外

克制不是一律少写。需要强调的少数位置应当写足、写透，正是这些位置与周围的克制形成对比。真正的错误是平均用力：每一段都写得很满，等于没有重点。

因此真正的技术难题不是"如何少写"，而是"在哪里多写"。通常需要写足的位置有三个：第一次进入核心空间时、人物的关键决定发生时、结局的最后一个画面。除此之外的描写，都应当以能否推进理解为标准来取舍。

## 描写的顺序

描写顺序本身就是一种引导。从大到小，读者会感到作者在逐渐聚焦；从小到大，读者会感到压迫感在上升。从人物的注意力出发（他先看到什么）比从空间逻辑出发更有效，因为前者同时交代了人物的状态。

最常见的技术错误是"摄影机式描写"：从门口写到窗台，从天花板写到地板，按空间顺序遍历一遍。这样的段落信息齐全但缺少焦点，读者读完不知道应该看哪里。修正方法是在段落开头给出焦点，其余细节围绕焦点组织。

## 描写的时机

描写不应该集中在场景开头一次完成。把描写拆成若干小块，分布在人物的行动之间，效果远好于一段集中的静态描写。人物每做一个动作，就顺手带出一个环境细节，读者的画面是随着动作逐渐拼出来的。

这种写法的另一个好处是它天然解决了"为什么现在要描写"的问题。当描写与动作绑定，描写就有了动机；当描写单独成段，它的存在理由只能由作者解释。凡是需要作者解释的东西，读者都不太会真正接收。

## 与文体的关系

克制原则在不同文体中的强度不同。在叙事文体里，克制近乎义务；在抒情散文里，适度的铺陈是被允许的，因为铺陈本身构成文章的节奏；在说明文体里，克制表现为术语的精确和修辞的节制，而不是画面感的强弱。判断标准始终是同一件事：读者是否需要作者替他完成判断。若不需要，作者就应该退后一步。
